# 秋 · 草原 (Autumn Grassland) 🍂

黄金时刻的风格化秋天草原,基于 **React 19 + TypeScript + Vite 7 + three.js**(`@react-three/fiber`)。

**100% 程序化生成 —— 零外部模型、零贴图下载。**

## 运行

```bash
npm install
npm run dev        # 开发预览
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
```

## 操作

- 拖动环视 · 滚轮推近(始终缓慢自动旋转,拖动后继续)
- 左下角滑杆调节风力,实时影响草与落叶
- 配乐默认播放;浏览器拦截自动播放时,首次点击或拖动自动开始,按钮可暂停/继续

## 技术要点

- **草**:15 万株实例化草叶(5 顶点/株,径向密度偏置 —— 近景密远景疏),`MeshLambertMaterial` + `onBeforeCompile` 顶点注入风场 —— 沿全局风向的行进阵风波纹,法线强制朝上避免双面光照噪声
- **地形**:值噪声 fBm 高度场,烘焙顶点色(枯金/橄榄/裸土补丁),正弦叠加蜿蜒土路,中央压平供相机活动
- **树木/岩石**:程序化圆润几何(圆柱干 + 细分球冠 merge、平滑着色),秋季色板,投射阴影
- **氛围**:Preetham 大气天空(drei `Sky`)+ 暖色线性雾 + ACES 色调映射 + Bloom/Vignette 后期
- **动态**:140 片翻滚落叶(实例化叶形几何,CPU 积分)、3 只盘旋飞鸟剪影、drei 体积云(贴图由本地程序化生成,无外网依赖)
- **状态**:zustand 桥接 UI 滑杆 ↔ 共享 shader uniform(`uTime` / `uWind`)
- **兼容**:启动前检测 WebGL2 与渲染器;软件渲染/低配设备自动降档(草量、阴影、后期),不支持 WebGL2 时显示静态预览与提示
